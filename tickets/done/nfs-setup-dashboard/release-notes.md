# Local NFS setup dashboard

- Source-built `server` and `client` commands open an embedded local browser interface.
- Review and approve exact setup, reconnect and drained-disconnect actions; administrator approval stays in the terminal.
- Inspect configuration separately from readiness, recover incomplete setup, and stop the dashboard without disconnecting storage.
- Choose folders with keyboard-friendly, draft-preserving navigation. Existing terminal commands and installed supervision remain supported.

Source-only delivery: no release was requested. Published v0.1.0 does not include this dashboard. Physical/field and general-user qualification remain separate.
