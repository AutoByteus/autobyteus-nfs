## Terminology / Tight Shared Structures
- **E (executor commit)**: actual reviewed main workflow checkout/dispatch SHA performing this attempt.
- **P (payload source commit)**: commit in the immutable annotated version tag and original publication.json. For bound recovery, never reassigned to E.
- **C (candidate commit)**: original candidate source, ancestor of P; original workflow/run identity is separately retained.
- **H (reviewed executor code commit)**: corrected source commit reviewed/tested before Delivery adds genuine authorization/evidence. H ancestor of E; all executable inputs at E must equal H.
- **SourceContext `{root, commit, repository}`**: bounded read-only source bytes at a precise Git commit, and the owning Git repository for ancestry/blob queries. It grants **no publication authority**.
- **PublicationContext**: distinct executor SourceContext, payload SourceContext, mode, original tag identity/binding and optional validated recovery authorization. No overloaded generic `source` field for two subjects.

## Key Tradeoffs, Risks And Implementation Guidance
A separate reviewed executor authorization adds bounded data/verification work, but avoids either violating immutability or endlessly rebuilding an unpublishable tag. The record is not cryptographic proof of human judgement: trusted repository integration and independent specialist evidence remain essential. Tight allowed changes and actual E freshness make that trust explicit.

Remote inventory and writes are not transactional. Recheck identity, use nonclobber endpoints and fail on ambiguity; do not claim recovery from every external mutation. Actual visibility/retention/upload/registry permissions remain observable gates. If interrupted, preserve precise attempted-stage receipts and use a new manual same-payload dispatch, never failed-job-only stale replay. Preserve original candidate/payload and all other-owner histories/caches. Stop owned processes and remove only owned scratch after evidence retention. No SD implementation/test/CI/publication action was performed in producing this design.
