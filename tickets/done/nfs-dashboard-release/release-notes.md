# AutoByteus NFS v0.2.0 — local setup dashboard

- Start a standalone local setup interface with `autobyteus-nfs server` or `autobyteus-nfs client` from the same executable.
- Share a folder or paste connection details, review the exact plan, and approve setup. Administrator authentication stays in the launching terminal, never the browser.
- Inspect saved configuration separately from fresh readiness, reconnect or resume incomplete setup, and safely disconnect only after users are drained.
- Browse directories with keyboard-friendly, draft-preserving selection. Closing management does not disconnect storage; existing CLI and service behavior remain available.

Supported native host contracts remain macOS26+ and Ubuntu24.04, private trusted-network NFS, one attachment per installation. No application dependency, remote management, new platform qualification, automatic upgrade or data migration is introduced.
